# 合成演示数据

`python main.py --mode demo` 使用固定种子42生成10个模拟靶点、160株模拟酵母、3个示例结构和6个剂量条件。表示、训练配对、响应均为合成数组；其中一个人为设置的正相关条件用于覆盖家族分解分支，化合物标识使用 `DEMO_` 前缀。结构字符串仅用于检查输出格式，不代表已测得的化学活性。

演示依次执行小维度 ridge 拟合、三成员 RRF 排序设计、生产代码的共模去除、双向筛选、每方向最多3对提名、确认、家族分解和候选导出。它使用99/199/199次置换以控制耗时，与正式分析的1000/100000/10000次不同。合成 ridge 和投影不替代历史 B2 训练，不使用 ESM-2 或 B2 模型权重。

提名来自同一合成响应数据；确认 BH 仅适用于提名家族，不校正前序选择。所有输出标为“合成演示，非科研候选”，不得合并到正式 results.csv。每次输入、拟合权重、配置、日志、种子和结果均保存在指定输出目录。

剂量使用任意演示单位。运行可重复生成输入，无需外部下载。该示例证明代码衔接，不证明正式研究结果已从原始数据重现。
