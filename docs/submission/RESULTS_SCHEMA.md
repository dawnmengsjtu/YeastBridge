# 候选清单字段与统计口径

当前 `results.csv` 为UTF-8编码、15列，模型版本 `B2-submission-v2-20261003`，含80条记录、78个靶点、5个化合物。每方向按标准化分数 `z=(rho-null_mean)/null_sd` 降序提名最多40对；零null_sd对应未定义分数，不优先提名。先取正向，再从负向top40中删除已选的相同候选对，不额外补位。最终CSV按方向和靶点名称稳定排序，候选编号不表示效力排名。格式依据为附件5允许的默认CSV，见 [TEMPLATE_BASIS.md](TEMPLATE_BASIS.md)。

| 字段 | 类型及含义 |
| --- | --- |
| 候选编号 | 唯一字符串；正式表 `YB-`，合成演示 `DEMO-` |
| 赛道 | 赛道三：离子通道、GPCR等药靶的小分子虚拟筛选 |
| 靶点 | 人源基因符号；演示为模拟标识 |
| 化合物_InChIKey | 化合物键；演示使用 `DEMO_` 标识 |
| 化合物_CID | 正整数形式的PubChem CID；缺失时空字符串，演示为空 |
| SMILES | 化合物结构字符串；正式导出不允许缺失 |
| 方向 | `+z`耐药富集或`-z`超敏 |
| spearman_rho | 无量纲，保留4位小数，范围[-1,1] |
| emp_p | 置换经验p值，保留6位小数 |
| q_bh | BH校正值，保留8位小数 |
| 剂量 | 响应文件中的原始数值，与单位列配对解释 |
| 剂量单位 | 来自冻结响应条件表；演示为arbitrary demo units |
| 证据等级 | 确认、家族分辨与残差检验的统计分类 |
| 模型与版本 | 方法名及精确B2提交版本；代码和输入哈希见 `.metadata.json` |
| 备注 | 分类依据或演示标识 |

默认导出以两个方向的确认记录合并计算BH，保留q≥0.1的记录并明确标为未过阈候选。残差升级阈值为0.05/本次确认记录数。确认BH不校正第一阶段提名选择，不能解释为全库错误发现率（FDR）。结构以SMILES表示，本流程不生成三维结构。

`uncertainty/monte_carlo_intervals.tsv`记录每对候选的置换次数、超越次数及95% Clopper–Pearson区间。100,000次确认置换的最小经验p值是1/100001。该区间仅量化给定候选和观测数据时的Monte Carlo误差，不覆盖测量误差、提名选择、药效或靶点特异性。

`--legacy`导出9月归档的80条记录，保留原先按方向分别校正的q值及原证据标签。它是历史复核入口，与当前提交版本分开标识。若报名平台另发专用字段模板，按实际模板映射，不改变统计值和对应模型。
