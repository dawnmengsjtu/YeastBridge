# 候选清单字段与统计口径

`results.csv` 使用 UTF-8 编码，15列。历史结果为80条记录、78个靶点、5个化合物，按方向和靶点名称排序；候选编号不代表效力排名。

| 字段 | 类型及含义 |
| --- | --- |
| 候选编号 | 唯一字符串；正式表 `YB-`，合成演示 `DEMO-` |
| 赛道 | 项目现有赛道名称，仍需与最终官方模板核对 |
| 靶点 | 人源基因符号；演示为模拟标识 |
| 化合物_InChIKey | 化合物键；演示为 `DEMO_` 标识，不冒充真实 InChIKey |
| 化合物_CID | PubChem CID；无法取得时为空，演示为空 |
| SMILES | 结构字符串；正式导出不允许缺失 |
| 方向 | `+z` 耐药富集或 `-z` 超敏 |
| spearman_rho | 无量纲，保留4位小数 |
| emp_p | 置换经验 p 值，保留6位小数 |
| q_bh | BH 校正值，保留8位小数 |
| 剂量 | 沿用响应数据数值，与下一列的单位配对解释 |
| 剂量单位 | 从冻结NPZ恢复；现有80条候选均为micromolar（µM），演示为arbitrary demo units |
| 证据等级 | 统计证据分类；不代表结合或机制验证 |
| 模型与版本 | 方法标识；精确代码、输入哈希见同名 `.metadata.json` |
| 备注 | 分类依据或演示标识 |

默认导出保留历史80条记录的所有值。原导出脚本读取两个方向各自确认文件中的 q 值，因此历史 `q_bh` 保持各方向的校正口径；不能将它们写成联合80对重新计算的值。

新运行的导出对两个方向合并后的经验 p 值计算 BH，并保留未通过 q<0.1 的记录且明确标为未过阈候选。残差升级阈值为0.05/本次确认记录数。两种口径均不校正第一阶段提名选择，不能解释成全库发现 FDR。

本项目不输出三维结构，现有清单不附 PDB/CIF。提交时须再核对赛道最终模板对字段名称、候选数量、缺失值、排序和精度的规定；当前未获得该模板，不能声称已按其验收。

新运行同时生成`uncertainty/monte_carlo_intervals.tsv`，给出每个候选置换超越概率的95% Clopper–Pearson区间、置换次数和超越次数。它量化有限置换的Monte Carlo误差，不能解释为药效、靶点特异性或筛选选择偏倚的置信区间。100,000次确认置换对应最小可报告经验p值为`1/100001`。
