# 最终结果格式的依据

本次提交按参赛者提供的附件5通用规则生成UTF-8 `results.csv`。附件5规定，未另行规定时可使用这种格式；必填信息包括候选编号、赛道、结构/序列、预测指标、模型和运行版本、备注。本仓库的字段契约见 [RESULTS_SCHEMA.md](RESULTS_SCHEMA.md)。

2026-10-03核对了[赛事通知](https://life.jlu.edu.cn/info/1090/6286.htm)与[附件发布页](https://jxgl.smu.edu.cn/info/1053/113985.htm)。通知列出的赛道三为离子通道、GPCR等药靶的小分子虚拟筛选，与本项目输出一致。通知指向的[官方赛事平台](https://competition.openlifesci-alliance.org/)在本次访问中无法取得可读页面；公开检索也未取得单独的候选清单文件。因此，本次使用附件5明确允许的默认格式，不宣称采用了尚未取得的另一份模板。

仓库将字段名称、数据类型、剂量单位、缺失值、候选数量规则、排序和精度明确写入结果契约，并由验证脚本检查。若赛事平台向已报名队伍另发专用模板，应按实际文件映射字段；不能据公开检索无结果断言专用模板不存在。
