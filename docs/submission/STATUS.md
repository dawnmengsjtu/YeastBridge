# 附件5核对记录

本记录依据参赛者提供的《第一届全球大学生生命科学挑战赛：AI模型与代码·提交规范与可复现性要求》，核对2026-10-03的 `B2-submission-v2-20261003` 提交版本。最终结果采用附件5明确允许的UTF-8默认CSV；赛道与格式依据见 [TEMPLATE_BASIS.md](TEMPLATE_BASIS.md)。

| 要求 | 提交材料与实际验证 |
| --- | --- |
| 环境与完整依赖 | 核心/完整CPU锁定文件、33项GPU训练依赖、R预处理环境；Python、系统、CUDA、驱动和硬件记录 |
| 源码与核心注释 | `scripts/`、`train.py`、`main.py`；主入口使用相对配置和可指定输出目录 |
| 最终训练模型 | 新B2完成6轮，最终checkpoint、输入、逐轮指标及日志哈希对应 |
| 训练入口与划分 | `train.py`、完整配置、逐样本split.tsv、pip freeze；训练160.3分钟 |
| 主运行入口 | `main.py --mode full`从冻结表示与权重运行全部14步；`predict.py`一键重新导出提交表 |
| 真实筛选复跑 | CPU、线程上限4，17.8分钟，80条结果；冻结记录再次导出的CSV与完整运行逐字节一致 |
| 可运行示例 | 无外部模型依赖的合成示例覆盖拟合/设计→筛选→确认→导出，并显式标记演示输出 |
| 数据来源与许可 | `data/datasets.json`登记全部数据用途、实际文件版本/哈希和获取证据；`THIRD_PARTY_DATA.md`逐项标注条款 |
| 数据处理 | GSE125162原计数重建的三个文件哈希一致；三组ESM-2索引及矩阵逐字节一致；HIP/HOP表达重建的8个数组字段一致 |
| 去重与泄漏防控 | 细胞/计数行重复检查；配对监督实体划分检查；披露随机细胞划分、上游预训练和结果提名复用的范围 |
| 第三方模型调用 | 模型名、上游来源和许可、输入序列/索引、表示参数、当前运行命令与输入输出哈希；不使用商业API |
| Model Card | 模型结构、用途、输入输出、训练状态、贡献和统计局限 |
| 结果与不确定性 | 15列CSV，编号/赛道/结构/指标/版本/备注及剂量单位；稳定排序；逐候选置换概率95%区间 |
| Notebook | 主入口及示例完整覆盖流程，适用附件5的非强制例外 |
| 分发与溯源 | 完整包含当前权重、筛选输入、训练输入归档、源码和证据；逐文件SHA-256；上游初始权重提供官方获取方式 |

运行 `python scripts/verify_submission.py` 可核验训练、资产、完整运行、候选导出、字段和数据披露的一致性。详细证据见[训练运行](../../models/training/evidence/submission-v2/run.json)、[筛选运行](../../repro/submission-v2-20261003/run.json)及本目录验证报告。该核对描述代码与附件5通用要求的对应关系，不替代赛事组织方的正式评测。
