## 完整包的训练证据索引

恢复原材料后添加 `models/training_manifest.json`，字段 `entrypoint`、`environment` 为仓库相对文件路径，`logs`、`splits` 为路径列表。内容应指向真实的 B2 训练材料，不可填入演示代码或其他模型的训练记录。打包工具检查这些路径是否存在；文件存在本身也不代表已通过科学审查。

```bash
python main.py --mode check
python main.py --mode full --output outputs/full
python scripts/build_submission.py --profile full --output dist/YeastBridge-full.zip
```

资产或训练证据未齐时，完整包命令会失败。`review` 包用于提前复核代码与格式，应与完整科研提交包区分。
