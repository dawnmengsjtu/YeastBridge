## 1. 与 V7 的关系（配方动机，全部来自已登记结果）

1. V7 臂 C 训于**原始** ESM2 空间，而 V5.1 注册语义是 **pc1 去除空间**上的
   配对监督；V8 把 C 搬回 pc 空间（npc∈{1,2,3}，仅按官方 train 对 AUC 选）；
2. 人/酵母两侧是**同一基座模型**的嵌入空间：跨物种对齐的正确先验是恒等映射
   加修正：新增 **identity-anchored ridge** 成员
   （W=(XᵀX+λI)⁻¹(XᵀY+λI)），缓解 510 对 × 1280 维的欠定；
3. V5.1 教训：秩集成优于单检索器，C = 三成员（ridge / anchored / PLS-k）
   行百分位秩平均，超参各自按 train AUC 独立选。

事后配置披露：属同数据迭代（第四轮），p 值不得按单轮预注册解读。
