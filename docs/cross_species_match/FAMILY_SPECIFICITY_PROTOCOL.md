# 家族特异性检验协议（EJ-dc 确认对的证据升级判定，2026-09-13 冻结）

前置：`ESM2_JOINT_DC_ADDENDUM.md` 两阶段确认 80/80 过门，但主张单位存疑
（家族内任务谱近同 → "化合物×家族" vs "化合物×靶点"）。本协议在任何
特异性计算之前冻结判据。2026-09-13 批准启动。

## 方法（确定性，全部基于已冻结 EJ-dc 导出分）

1. **家族定义**：1175 个 EJ-dc 任务谱（池 1279 株列，尾段 3 株除外）行
   Pearson 相关 → average-linkage 层次聚类 → 距离阈值 0.1（=相关 0.9，
   预声明，不调参；0.7 阈值仅作描述性敏感性）。家族 = 尺寸≥2 的簇；
   含≥1 提名靶点的家族进入检验。
2. **家族均值轴（主检验）**：家族全体成员（含未提名者）dc 分数逐株均值
   → 排序 → 任务表 `FAM_<id>`。对每个（家族, 化合物, 方向）单元用对应
   方向配置重检（n_perm=10,000）。
3. **残差轴（次检验）**：提名靶点 t 的谱去家族公共分量
   r_t = s_t − (⟨s_t,m_F⟩/⟨m_F,m_F⟩)·m_F → 排序 → 任务表（原靶点名）。
   80 对按提名方向重检（n_perm=10,000）。

## 判据（冻结）

- **R1（升级到"化合物×靶点"）**：某对残差轴 emp_p < 0.05/80 = 6.25e-4，
  且残差 |rho| > 0；仅该对升级。
- **R2（主张维持在"化合物×家族"）**：无对满足 R1，且家族均值轴复现关联
  （单元 emp_p < 0.05/单元数，rho 与全轴同号）。
- 方差分解表（每提名对：全轴 rho / 家族均值轴 rho / 残差轴 rho 与残差
  方差占比）随结果强制披露；残差占比过低的对，R1 即使显著也标注
  "残差检验功效受限"。
