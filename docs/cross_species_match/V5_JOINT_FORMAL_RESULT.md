# V5/V5.1 联合增益正式结果数据卡

结论先说：**联合增益成立（GO）**。配对监督对齐（轨道 A）与多路秩融合（轨道 B）
两种联合实现都在预注册门下显著优于非联合基线。v3 的 `NO_GO_JOINT_ROUTE_SINGLE`
针对的是"19 类分类 + 分数等权融合"，该范围结论仍成立且已被本项目复验；项目级
状态由本卡取代（`configs/v5_joint.formal_status.json`）。
