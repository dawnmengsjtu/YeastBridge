## 跨轮规律（V5.1/V7/V8 合并读法，结论级）

1. **联合增益（配对监督 vs 无对齐）在蛋白表示上最大且高度显著**（+0.131，
   CI 远离 0），在 GO 签名表示上小但显著（+0.074），门 A 在两条轴上都过，
   esm2 轴效应量近乎翻倍；
2. **融合增益与表示强度成反比**：弱表示（GO-BP ES）下五路融合过门
   （V5.1 p=0.0024），强表示（蛋白）下融合无增量（V7 p=0.124、V8 p=0.425，
   两轮独立一致），门 B 失败是结构性的，不是配方未调好；继续配方搜索
   属于对着已登记零假设做门购物，本项目纪律禁止；
3. **无监督去 PC1 是蛋白轴的天花板级操作**（0.9638）：配对监督把 C 从
   0.752（V7 原始空间）提到 0.877（pc 空间集成），仍不足以在池化 AUC 口径
   超过 B；全池排序口径两者打平。

## 主张边界（对外口径）

- **可讲**：esm2 轴上，人-酵母配对监督联合臂对无对齐单物种基线的增益显著
  （门 A 主门+次门全过，Δ+0.131 CI[+0.071,+0.193]，历轮最强）；联合臂与
  无监督去 PC1 在全池排序口径不可区分，两者构成去相关的双证据线。
- **不可讲**：联合臂胜过无监督去 PC1（池化 AUC 口径显著为负）；融合式
  joint（门 B）在蛋白表示下有效。
- 产品线建议口径：esm2 + 去 PC1 为主检索器（any-hit@10 0.911）；配对对齐
  C 臂并列为独立显著证据线/重排序成员。
