# 当前论文方法

论文的核心创新是将人类靶点连接到酵母扰动读出；主要应用价值是复用低成本酵母测量，减少新增人类筛药实验的需求。模型选择与统计处理支撑这两点。

## 模型效能、模型组成和筛药

模型效能由联合功能检索和训练数据效率评价；模型组成由GO/ESM-2、Geneformer/scGPT/scFoundation及酵母迁移路线比较确定；筛药结果为25对候选、7个靶点、18种化合物及6对具有积极结构证据的关联。比较使用原有数据划分和评价单位。

独立迁移比较包含Protein injection、Ortholog mapping、From scratch、scYeast和Graph propagation。ESM-2是共享蛋白表征及联合算法内部成员，不单独恢复为独立对照。scFoundation来源于人类表达预训练，并通过蛋白注入适配酵母；人类序列查询通过ESM-2进入最终筛选。

## 从人类序列到酵母扰动

三成员分别为`direct_pc1`、`aligned_c_ensemble`和`b2_verbatim`，RRF偏移固定为20。配对映射使用510个训练配对；直接成员去除1个蛋白特征PC，对齐成员去除3个PC，ridge和anchored-ridge均为λ=1，PLS取8个成分。

蛋白注入严格按训练输入执行：原始平均池化ESM-2向量 → 带偏置投影 → 归一化。不能提前归一化输入。全部5,865株测量与表征均可用的酵母菌株参与筛选。先限定338个离子通道相关条目，再计算跨靶点均值和第一残余主成分；不在1,175个历史混合靶点上校正后再截取338个。

## 从酵母扰动到候选化合物

响应来自公开HIP/HOP的20-mer条形码重建。5,869株×3,850条件包括3,356个化合物条件和494个车辆条件；筛选使用5,865株与3,250种化合物。`z_score`是历史数组键名，值为log2条形码丰度对比。

正负方向分别取同一化合物各条件的最大相关性。校准在HIP/HOP内部置换，保存条件索引；全库最大统计量覆盖全部靶点、化合物、方向及条件选择。完整谱338×3,250×2=2,197,000个方向假设；可估计残差95×3,250×2=617,500个方向假设。额外置换100,000次，种子20261024。

家族成员固定于原覆盖范围的338条目分析。完整谱和残差可各自选择最优条件，但需同靶点、同化合物、同方向且两个全库P均≤0.05。完整谱层保留5,216对关联；两层交集为25对。模型权重、三成员和RRF参数在本次仓库维护中未变更。
